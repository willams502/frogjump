# 🐸 FrogJump

Jogo arcade multiplataforma desenvolvido com **HTML5 Canvas** e **JavaScript**, com suporte a PWA e empacotamento mobile via **Capacitor**.

## ✨ Funcionalidades
- Jogabilidade arcade responsiva no navegador e dispositivos móveis
- Sistema de pontuação e persistência de recordes locais
- Loja/sistema de skins desbloqueáveis
- Áudio integrado e suporte offline (Service Worker)

## 🛠️ Tecnologias
- JavaScript (ES6+)
- HTML5 Canvas & CSS3
- Capacitor & PWA (`manifest.json`, `sw.js`)

## 🚀 Como executar localmente
```bash
git clone https://github.com/willams502/frogjump.git
cd frogjump
# Abra index.html em um servidor local, ex:
npx serve .
```
